## Tech Stack & Tools

### Backend

- **Spring Boot 3.2.x** – Core application framework
- **Spring Data JPA** – Database abstraction layer
- **Spring Security + JWT** – Authentication and endpoint security
- **Spring Validation** – Request body and data validation

### Database

- **MySQL 8.x** – Primary relational database for production data
- **Hibernate** – Object-Relational Mapping (ORM) framework
- **H2** – In-memory database for fast, isolated testing

### Tools & DevOps

- **Maven** – Dependency management and project build tool
- **Postman** – Manual API testing and request collection
- **Swagger** – Automated REST API interactive documentation
- **Docker** – Containerization for local environment consistency
- **Railway** – Cloud platform used for free application hosting
